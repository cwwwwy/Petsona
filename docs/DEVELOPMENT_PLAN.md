# Petsona 开发计划

本文档是 Petsona 的长期开发计划，按阶段维护当前目标、状态与完成条件。对应的实现和验收证据集中记录在 [开发执行记录](DEVELOPMENT_EXECUTION.md)；默认不为每个阶段另建一对计划/执行文件。

## 当前基线（截至 2026-10-13）

- 当前版本为 0.1.0，处于首次正式发布准备。
- M6-A 发布前清理已完成并经用户验收。
- 项目目录与 Git 历史收束已完成；对应执行结果保留在开发执行记录的“项目收束”条目中。
- Windows 与 macOS 桌面主体功能已通过此前验收；执行记录中仍列出的专项平台/硬件验收不因阶段总结而自动关闭。
- M6-B 尚未开始；目前没有正式安装包或 GitHub Release。

## 开发阶段

| 阶段 | 目标 | 状态 | 完成条件 |
|---|---|---|---|
| M6-A：发布前清理 | 清理发布前项目内容与 Git 历史。 | 已完成 | 用户已验收；执行证据见开发执行记录。 |
| M6-B：安装包与发布准备 | 准备 Windows/macOS 可交付候选包，完成对应平台的签名/公证准备、运行时处理及安装生命周期验收。 | 待开始 | 两个平台候选包通过必要的自动与人工验收；首次安装、升级、登录自启、卸载后的数据保留及首次打开行为有当前版本证据；未解决问题明确记录。 |
| 首次正式发布 | 在 M6-B 验收通过后，准备发布说明与平台产物，按分平台发布约定完成最终发布核对。 | 待 M6-B 完成 | 发布检查通过；正式版本、标签及 GitHub Release 由用户按项目 Git 规则操作。 |
| 首发之后 | 根据首发结果和实际反馈确定后续维护或产品方向。 | 尚未规划 | 用户确定范围后再加入计划；当前不预设 M7 功能或时间表。 |

## M6-B 范围

- Windows 安装包与运行时处理。
- macOS 安装包、签名/公证和首次打开体验。
- 干净环境首次安装，以及升级时保留宠物、角色、记忆和设置。
- 登录自启行为，以及卸载后保留用户数据。
- 候选包发布流程与完成判定。

详细验收矩阵、命令、平台依赖与责任在开始 M6-B 实施前补入本计划。证书/账号、支持的系统范围、安装包格式和干净环境可用性目前尚未在现有记录中确认；不得将它们视为已就绪。容易人工完成的检查优先列为简短人工步骤，不为此增加复杂自动脚本。

## 已完成的项目收束范围

项目收束阶段清理了过期开发文件、一次性脚本和可再生成产物，保留两端构建/回归入口、产品代码、测试夹具与依赖锁；完成本地及 GitHub 历史重建。计划概要见本节，命令、回归与 Git 状态证据见[开发执行记录](DEVELOPMENT_EXECUTION.md)。

## 维护约定

- 阶段状态随实际证据更新；人工验收未完成时标为待验收，不以构建成功替代。
- 明确区分计划范围、已完成事项、延期事项与未决定事项；未经用户确认的后续方向不写成承诺。
- 阶段验收要求按 REQ 编号记录自动与人工完成条件；执行结果只更新到对应执行记录，不降低原验收标准。
