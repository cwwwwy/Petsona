## 根因速记（已定位，勿重新推导）

- **winit 重设整份窗口样式（偶发闪边框真根因）**：鼠标穿透 / 显示等 flag 变化会触发 winit 重算 GWL_STYLE
  并把 `WS_CAPTION` / `WS_THICKFRAME` 加回来，透明子窗因此闪一帧系统边框。修法：窗口过程拦截 `WM_STYLECHANGING`
  就地剥掉这些位；输入框窗口常驻可见（不再 Visible 切换）+ 每次打开重做隐藏 warm-up + 显示后补一次 strip。
  守卫：连续 12 轮开关，可见帧样式必须始终 `0x96000000`。
- **子窗的 1px 非客户区（白线真根因）**：egui viewport 窗口保留 1px 非客户区，客户区原点比窗口低 1px ——
  顶部 1px 被系统画白（「白线」），底部 1px 被裁（「下方横切」）。`SWP_FRAMECHANGED` 单独发没用，
  DWM 边框属性也没用。修法：窗口过程处理 `WM_NCCALCSIZE`（wparam!=0 返回 0）+ `WM_NCPAINT` 返回 0，
  并在安装子类后强制一次 `SetWindowPos(SWP_FRAMECHANGED)`；可激活窗口用 frameless-only 子类（不强制 NOACTIVATE）。
- **子窗不能停止渲染**：egui 会销毁未渲染的 viewport，下次显示就是新 Win32 窗口（观察到「偶发重启」）。
  修法：气泡 / 影子 / 输入框每帧都调用 `show_viewport_immediate`，用 `with_visible(false)` + 空内容做隐藏。
- **影响缩放的量要用 `pet_size()`**：`pet_window_size()` 的宽度被 `PET_WINDOW_MIN_WIDTH` 钳制，
  小档位窗口不缩；影子 / 注视等按精灵尺寸计算的都不能用窗口宽。
- **winit 忽略非 resizable 窗口的运行时 resize**：`.with_resizable(false)` 的窗口调 `.with_inner_size()` 不会生效，
  影子窗口因此一直是最初的尺寸。修法：创建时直接给最大尺寸，内容在窗口内缩放。
- **`TextEdit::frame(Frame::NONE)` 忽略 `.margin()`**：margin 只在默认 frame 下生效；要撑满容器高度用
  `.min_size()` + `.vertical_align()`。
- **子窗再现的边框 / 滑入**：egui 会回收长时间未渲染的 viewport —— 气泡 / 影子 / 输入框每次重新显示都是**新建 Win32 窗口**，`warm-up → 设属性 → 显示` 只对首次有效。修法（已实现）：隐藏时重置 warm-up 标志，每次重建都重做 warm-up；`style_popup_window` 同时 `clear_dwm_frame_hwnd` + 每帧重申样式。
- **影子视觉间距**：40pt 命中窗必须完全避开宠物（窗口顶边只在宠物下方 2pt），所以静止影子画在窗口顶部附近而不是窗口中心；宽度 = 宠物窗宽 × 0.19（半径 clamp 10–44pt）。
- **设置窗多屏**：`default_settings_position` 用 `viewport().monitor_size`（只有尺寸、无原点），x 夹在 `0..width` → 副屏原点非 0 时必然落回主屏。修法：改用 `PlatformHost::monitor_work_area` + 宠物窗口物理矩形，在**全局坐标**里定位并夹到该显示器工作区。
- **caret 注视**：`cursor_within_gaze_range` 的椭圆按宠物尺寸算，输入框比宠物宽得多，光标在远端时 dx 超界。修法：`conversation_cursor` 存在时跳过范围判定（保留死区）。
- **重力越界**：拖动直接发 `OuterPosition` 无夹取；`update_gravity` 遇到 `rect.y >= floor` 直接判 grounded。修法：重力开启时拖动按显示器工作区夹取，松手后吸附回 floor。
- **注视丢帧**：`GAZE_FRAME_MS = 40.0`（25fps），帧步进用 `floor(elapsed/40ms)`，快速移动 + 稀疏重绘会一次跳多帧。修法：注视激活时 ~16ms 步进 + 帧对齐重绘。
- **气泡慢**：`on_pet_click` → `trigger_greeting`（DeepSeek 线程）返回 true 时不立即显示本地气泡，要等网络回复。修法（已实现）：700ms 内无回复先显示本地短句，模型回复到达后替换。
- **子窗淡入 / 边框**：气泡与影子只在 warm-up 时禁用一次 DWM 过渡，之后 `Visible(false/true)` 切换仍会播放系统过渡；`style_popup_window` 未关闭 DWM 非客户区渲染。首选修法：常驻窗口 + 内容级显隐；备选：每帧重申属性 + `DWMWA_NCRENDERING_POLICY` 禁用。
- **影子过窄**：`draw_shadow_button` 固定 10→17pt 半径，与宠物宽度 / 缩放无关。修法：按宠物可见宽度计算（需同步调整影子窗口尺寸，保持 40pt 交互窗不压到宠物）。
- **输入框对齐**：单行文本用 `top_down(Align::Min)` + margin 6 → 偏上；`Frame::stroke` 在展开态仍画边框。修法：按内容进度垂直居中、描边随展开淡出。
