# macOS 桌面陪伴能力推进：执行契约

## 身份、授权与基线

- 任务 ID / 版本 / 日期：macos-companion-evolution / 1.2 / 2026-10-04。
- 用户目标：在 Codex 宠物完整交互基准上，完善聊天、可控记忆和可由用户材料塑造的人格；逐阶段实施和验收。
- 用户决定：固定 Codex 基准版本 26.930.31428；气泡回复并按需查看按宠物保存的聊天历史；流式回复；自然简短但不硬截断；明确表达可自动记忆、推断习惯需确认；人格支持粘贴/TXT/JSON 聊天记录，以及人物名字和可选文字材料；关闭聊天历史与关闭长期记忆分开；关闭任一保存项不删除既有内容；人物参考不联网；移除“立即活动”和日常“测试问候”；2026-10-04 进一步收束：移除模型/记忆调参及问候冷却/字数界面，保留已有配置；基准实际包含的影子、多屏、Retina、Spaces 行为纳入验收。
- 范围：macOS 原生界面及必要共享 Rust/runtime/FFI；Windows 只做共享 ABI/命令投影的兼容接线与完整回归，新增 Windows UI 不在本任务范围；最低 macOS 26。
- 非目标：Codex 账号、任务、项目功能；云同步；微信数据库读取、图片/语音分析；人物联网检索；语音；重力及自动活动提醒。
- 基线：main，HEAD 07400ce，工作区干净，本地 origin/main 落后 1 个提交。
- Codex 对照：本机安装包版本 26.930.31428；正式交互数值须由锁定版本的实际桌面观察和 bundle 资源双重记录，不能把本仓库现有注释直接作为基准。原始 Codex 安装资源不复制进仓库。

## 必须保持的约束

- ABI 3 结构体布局、所有权与现有枚举编号保持；若实现发现无法追加兼容接口，记录 CR 并暂停受影响 REQ。
- runtime 持有文件/网络/取消和请求序列；core 不新增文件/网络 IO；Swift 只呈现投影。任何晚到结果必须校验宠物、人格与请求 ID。
- 新对话/记忆设置默认为开启；旧配置缺字段使用向后兼容默认。关闭历史/记忆不删除数据；删除分别确认，原子写失败保留旧文件。
- 历史和记忆分别保存、注入模型与清理。memory enabled=false 后聊天和问候都不获取长期记忆。
- 人格导入/生成在当前宠物稳定 persona id 上应用，保持一宠一人格及现存记忆。未确认内容只入候选，不伪装成事实。
- 人格来源材料作为数据而非指令；采用 JSON 输出时严格反序列化与字段校验，失败时不覆盖正式人格。
- 不引入第三方依赖；现有 ureq 3.4.1 上实现 SSE。测试使用本地 HTTP stub、隔离数据目录/端口/自启/假密钥。
- 用户已同意四阶段人工验收；每阶段都记录人工状态。不得因阶段门禁未通过把阶段标为完成。
- 不 add/commit/push 或改分支。交付给出分组摘要与用户可执行命令。
