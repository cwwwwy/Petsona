# Petsona 桌面壳验收清单（Rust + TypeScript）

适用对象：`apps/desktop`（重建中的新壳）。旧前端（C#/WinUI、Swift/AppKit）的验收记录不是当前验收依据，
仅作为历史证据保留在 git（完整快照：`6bca241` 及以前）。

## 0. 准备

- 隔离数据目录：`PETSONA_HOME=%TEMP%\petsona-desktop-verify`（验收专用；日常实例不动）。
- 协议端口：日常 `17872`；验收实例固定一个独立端口（例如 `17873`），两者可共存。
- 测试宠物：自绘夹具 `crates/petsona-core/testdata/v2-test-pet`（V2 8×11，无第三方素材）；无内置宠物。
- 自动测试必须隔离数据目录、端口、自启值名与凭据，不得启动默认用户实例。
- 自动冒烟（`scripts/desktop-smoke.ps1`）**不移动鼠标、不注入输入**；A 段中的鼠标类项目（穿透、拖动、夹取、光标）
  与注视观感均为**人工验收**，由用户手动执行。

### E. 协议与状态（语义与旧版一致）

| # | 操作 | 预期结果 |
|---|---|---|
| E1 | `GET /health`、`GET /pets` | 返回 pet / persona / state 等字段与本地宠物 id 数组 |
| E2 | `POST /state` 带 `ttlMs:10000` | 状态切换并显示气泡，约 10 秒后回 idle |
| E3 | `ttlMs:0` 粘滞 | 一直保持，直到同 source 覆盖或更高优先级其他 source；`action:"clear"` 解除 |
| E4 | 非法状态名 | HTTP 400，状态不变 |

手工命令（Windows PowerShell，端口按验收实例替换）：

```powershell
# E1
Invoke-RestMethod http://127.0.0.1:17873/health | ConvertTo-Json -Depth 5
Invoke-RestMethod http://127.0.0.1:17873/pets

# E2 TTL 回退
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:17873/state -ContentType 'application/json; charset=utf-8' `
  -Body '{"source":"win-verify","state":"waiting","message":"Windows 验证","ttlMs":10000}'

# E3 粘滞与解除
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:17873/state -ContentType 'application/json; charset=utf-8' `
  -Body '{"source":"win-verify","state":"running","message":"不过期","ttlMs":0}'
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:17873/state -ContentType 'application/json; charset=utf-8' `
  -Body '{"source":"win-verify","action":"clear"}'

# E4 非法状态
try { Invoke-RestMethod -Method Post -Uri http://127.0.0.1:17873/state -ContentType 'application/json; charset=utf-8' -Body '{"state":"nope"}' }
catch { "HTTP " + [int]$_.Exception.Response.StatusCode }
```

状态优先级：`failed` 90 > `waiting` 80 > `running` 70 > `review` 60 > `waving`/`jumping` 40 > look 行 20 >
`running-left/right` 10 > `idle` 0；同一 source 必然覆盖自己；不同 source 需严格更高优先级；
用户交互不打断 agent 状态；`action:"clear"` 大小写不敏感、同 body 与 `state` 并存时 clear 优先。
